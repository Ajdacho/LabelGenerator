                  LabelGeneratorGUI
======================================================

Author: Filip Cieśla
Version: 1.1
License: MIT

About the Software:
LabelGeneratorGUI is a WinUI 3 desktop application designed to automate the generation of print-ready PDF product and care labels. It dynamically parses configuration and styling rules (such as material translations and customer style overrides) from a JSON file.

Implementation Details:
The application is highly self-contained. PDF generation is built utilizing pdfgen C library and native C++ streams. Excel (.xlsx) files are parsed without external C++ libraries by utilizing a lightweight PowerShell COM interop to convert them to CSV on the fly. Image processing and resizing are handled seamlessly via native Windows GDI+.

Required External Libraries and Dependencies:
- pdfgen by Andre Renaud (lightweight C PDF generation library - https://github.com/andrerenaud/pdfgen)
- nlohmann/json (single-header C++ library for parsing config.json - https://github.com/nlohmann/json)
- Windows App SDK / WinUI 3 (Microsoft framework for the Graphical User Interface)
